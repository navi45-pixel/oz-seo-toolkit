Skills Hub — 25 integrated SEO skills

AUTO skills run inside every free audit; PLAYBOOK skills are guided checklists you can work through. All knowledge is built into this toolkit.

⚙️ seo-technical AUTO

9-category technical audit: crawlability, indexability, security headers, URL structure, mobile, Core Web Vitals, JS rendering, Googlebot 2MB limit, redirect chains, mixed content, AI-crawler management.

🤖 seo-geo AUTO

AI Search / GEO: citability signals (question headings, quotable definitions, statistics, lists), E-E-A-T bylines, freshness, training-vs-citability bot taxonomy (OAI-SearchBot, Claude-SearchBot…).

📍 seo-local AUTO

Local pack factors: NAP, click-to-call, opening hours, review markup, service-area vs brick-and-mortar detection, Australian state/city mentions, ABN, geo meta.

🧩 seo-schema AUTO

Structured data: JSON-LD detection, deprecated types (HowTo, SpecialAnnouncement…), Microdata/RDFa fallback, FAQ rich-result retirement note, Product/Offer completeness.

🗺️ seo-sitemap AUTO

Sitemap discovery via robots.txt + fallbacks, URL count, lastmod coverage, legacy changefreq/priority flagging.

🌐 seo-hreflang AUTO

Hreflang validation: ISO code correctness (flags en-uk), self-reference, x-default, https consistency.

📷 seo-images AUTO

Image SEO: alt coverage, width/height for CLS, WebP/AVIF adoption, descriptive filenames.

✍️ seo-content AUTO

Content quality: word count, readability, keyword stuffing, title↔H1 alignment, Who/How/Why helpful-content proxies, AI-citation front-loading.

💫 seo-sxo AUTO

Search Experience Optimisation: primary CTA presence, page-type/keyword intent fit guidance.

🛒 seo-ecommerce AUTO

Shop detection (Shopify/WooCommerce), Product/Offer schema with priceCurrency & availability.

🗺 seo-maps AUTO

Maps intelligence: Google Maps embeds, review widgets (Trustpilot/ProductReview/Tripadvisor), GBP integration signals.

📊 seo-audit AUTO

The scoring framework itself: weighted categories, critical/high/medium priority fixes, plain-English recommendations.

🔁 seo-drift AUTO

Change detection: every audit is snapshotted; re-runs show score & category drift over time (“88 → 92, +4”).

🔗 seo-backlinks PAGE

Free backlink strategy: our AU directory + curated free sources (GBP, Bing Places, TrueLocal, Qwoted, Featured…), safety rules, AI-era link earning.

🎯 seo / master skill HUB

The router: decides which sub-skills apply to your task and in what order — mirrored by our audit running every relevant module at once.

🧮 seo-cluster PLAYBOOK

Topical authority: map 1 pillar + 6–12 cluster pages per money topic; interlink hub-and-spoke; one search intent per page.

🕵️ seo-competitor-pages PLAYBOOK

Reverse-engineer rivals: list their top 10 pages, classify page type, note angle/gaps, then brief a better page (use with seo-content-brief).

📝 seo-content-brief PLAYBOOK

Before writing: define intent, target question headings (mirror our “question headings” check), word range, internal links, schema plan, citable stats.

📈 seo-plan PLAYBOOK

90-day roadmap: weeks 1–2 technical fixes from your audit, 3–6 content clusters, 7–12 links + local citations; review drift weekly.

🔁 seo-flow PLAYBOOK

End-to-end workflow: audit → plan → clusters → briefs → content → schema → links → drift review. Follow in order for compounding wins.

📄 seo-page PLAYBOOK

Single-page optimisation loop: title/desc CTR rewrite, H1 with intent, answer-first intro, FAQ block, internal links in/out, schema, then re-audit here.

⚙️ seo-programmatic PLAYBOOK

Template pages (suburb × service): >60% unique text per page, pass the “swap test”, unique photos/FAQs, else risk doorway-page penalties.

🎨 seo-visual / seo-image-gen PLAYBOOK

Cover images, OG art and diagrams: generate branded visuals, compress to WebP, add width/height + descriptive filenames before upload.

📈 seo-google PLAYBOOK

Free Google stack: Search Console, PSI/CrUX, Rich Results Test, Trends, GBP, Business Profile posts — link out from our audit page quick tools.

📊 seo-dataforseo OPTIONAL

Optional paid-data add-on (volumes, backlink DBs, tech detection) if you ever want it. Not needed here — this toolkit stays 100% free.

How the integration works

Every AUTO skill above contributes live checks to your audit score. PLAYBOOK skills are strategy workflows that need human judgment — we surface them as checklists so nothing from the knowledge base is left out.
