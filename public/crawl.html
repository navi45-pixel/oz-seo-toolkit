A polite crawler, by design

This crawler identifies itself honestly, obeys robots.txt including Crawl-delay, throttles per response speed, backs off when a site pushes back, and never crawls query-string URLs. Sites that block it are reported as blocked — never silently skipped — so the report stays honest about what it did and didn't see.
